## The minimum viable start

If you don't want to do any of that yet — here's the whole system in four steps:

1. Pick a zone in your space
2. Give it a two-letter code (workshop = WS, kitchen = KT, garage = GR)
3. Write the code on a piece of tape
4. Put the tape on the shelf

That's it. The system is running.

Every tool in this repo is an upgrade layer on top of that foundation.
