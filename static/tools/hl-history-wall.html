The Tractor That Never Left

"Purchased in 1939 for $1,050. My great-grandfather financed $700 and his daughter Doris put up the $350 cash. It has never left the property. It still runs."

Dr. Harry Benjamin Piper's 1939 Ford 9N sat in the same machine shed in Sharon, Wisconsin for 87 years. Fully restored by his descendants. The address in the HL System is the same address it has always had — the machine shed, main floor, second section, mount zero.
